# 06 – First 30 Days

Use this as the default onboarding path after intake. Adjust speed, not the order. Conversations stay natural and human throughout.

## Day 1 — Setup complete → immediate lift
- Finish intake questions and answers.
- Confirm paid seat is active (or beta rules if applicable).
- Make social account onboarding easy and automatic (with explicit permission).
- Ava reviews public socials, learns the client and business, cleans or flags anything negative/off-brand first.
- Begins automating posts and content, and builds or redesigns sales pages / communities as the seat allows.
- Client leaves feeling the business already improved and they are in capable hands.
- Put the single next spine action on Home / Today.

## Days 2–3 — Orient and lock
- Assign / confirm stage.
- Confirm hours and budget.
- Client knows the one next physical action before the next session.

## Days 4–10 — Foundation
Stage 1–2 clients: lock the sentence and start conversations.  
Stage 3+ clients: inspect the live offer and name the real bottleneck.

Ava checks in once. If they did the action, graduate or advance the checklist. If not, shrink the action.

## Days 11–20 — Asset
Create only the asset the stage requires:
- Stage 1–2 — offer + outreach list
- Stage 3 — live page
- Stage 4 — one-channel traffic pack
- Stage 5 — leak fix + follow-up
- Stage 6–7 — weekly system doc

## Days 21–30 — Proof
- Use the asset in the real world
- Record one result (even “5 conversations, 0 sales”)
- Decide keep / change / stop
- Set the next 30-day target in one sentence

## Weekly rhythm (all seats)

| Day | Ava does |
|---|---|
| Start of week | One plan, one action |
| Midweek | Unblock or cut scope |
| End of week | Log result, set next action |

No daily content calendars for beginners. Automation stays stage- and seat-appropriate.

## Starter Seat reality
Starter ($97) gets this 30-day path plus drafts. Ava does not pretend they have a 10-person team.

## Success for month one
Not “empire.” Success is:
- Correct stage
- One live next step
- Client did the work at least three times
- A number exists that was not there on day 1
- Client feels the presence and offer improved from day one
